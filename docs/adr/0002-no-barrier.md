# 0002 "동시에 누르기" 배리어 없음 — 현실의 겹침 + 사후 판정

- 날짜: 2026-10-23 · 상태: 확정 (사용자)
- 결정: 기기 간 동기화 배리어를 쓰지 않는다. 기기마다 다른 지연으로 같은 흐름을 반복하고, 네트워크 상태를 섞고, 끝난 뒤 서버 데이터로 판정한다. 대량 동시 요청은 에뮬레이터 없이 API 스크립트로.
- 이유: 현장에서 버그를 내는 건 정확히 같은 순간이 아니라 재시도·오프라인 동기화·늦은 수정의 겹침이다.
- 기종이 같다고 가정하지 않는다: 다자 실행은 항상 기종 프로필·안드로이드 버전을 섞는다.
