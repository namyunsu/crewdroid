# Security

Report a vulnerability privately with a GitHub security advisory: the repository's **Security** tab -> **Report a vulnerability**. Please do not open a public issue for it.

Include what you found, the command or file involved, and steps to reproduce. You will get an answer in a few days. crewdroid is maintained by one person, so fixes are best effort.

Supported: the latest published version.

crewdroid runs `adb` against local emulators and starts a local HTTP proxy and sample server. Reports about those, about path handling, or about the MCP server running commands it should not are in scope.
