이 폴더의 spec.md 대로 안드로이드 앱을 만들어라. 사람은 답하지 않으니 끝날 때까지 혼자 판단해서 진행한다.

1. 앱을 만들고 빌드한다.
2. 에뮬레이터에 설치해 명세의 기능을 실제 화면에서 하나씩 눌러 확인하고, 깨진 것은 고친다. 빌드-설치-확인을 필요한 만큼 반복한다.
3. 에뮬레이터 3대를 띄워 기사 3명이 같은 콜들을 잡고 완료하는 상황을 실제로 돌린다. 서버에 동시성 문제(한 콜을 두 기사가 잡음, 정산 중복 등)가 있는지 찾는다. 응답을 잃는 상황도 시험한다. 서버는 고칠 수 없으니 찾은 문제와 증거를 result.md 에 적는다. 없으면 없다고 적는다.
4. 띄운 에뮬레이터를 모두 끄고 끝낸다.

규칙: 기기는 에뮬레이터만 쓴다. 이 PC 에 USB 폰이 꽂혀 있을 수 있는데 절대 건드리지 않는다. 포트 5554 부터 쓰는 사용자의 다른 작업이 없으니 에뮬레이터는 마음대로 띄워도 된다. 빌드 산출물 외의 임시 파일은 이 폴더 안에 둔다.
