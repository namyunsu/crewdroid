# 대리콜 기사 앱 명세

대리운전 기사용 안드로이드 앱이다. 패키지 `dev.crewdroid.daeri`. 빈 프로젝트(이 폴더)에 Kotlin 으로 만든다.

## 화면

1. 로그인: "기사 이름" 입력칸(한글 입력 가능), "근무 시작" 버튼. 이름은 앱을 다시 켜도 남는다.
2. 콜 목록: 맨 위에 "대리콜 · <이름>" 과 "오늘 수입 <금액>원". 그 아래 대기 중인 콜마다 출발지 → 도착지, 요금, "수락" 버튼. 2초마다 새로고침한다. 출발지·도착지가 길어도 "수락" 버튼이 잘리면 안 된다.
3. 운행중: 수락에 성공하면 나온다. "운행중", 출발지 → 도착지, 요금, "운행 완료" 버튼. 완료하면 콜 목록으로 돌아가고 오늘 수입이 늘어난다.
4. 다른 기사가 먼저 잡은 콜이면 목록으로 돌아가 빨간 글씨로 "이미 배차된 콜입니다" 를 보여 준다.

망이 끊겨도 수락과 운행 완료는 사라지면 안 된다. 망이 돌아오면 다시 보낸다.

## 서버

이미 떠 있다. 소스는 없다. 에뮬레이터에서 주소는 `http://10.0.2.2:5597`, 이 PC 에서는 `http://127.0.0.1:5597` 이다.

- `GET /calls` → `{"calls":[{"id","from","to","fare","version"}]}` 대기 중인 콜
- `PUT /calls/<id>/driver` 본문 `{"version","driverId","name"}` → 200 배차 성공, 409 이미 배차됨
- `POST /trips/<id>/complete` 본문 `{"driverId","fare"}` → 200 `{"earned":<이 기사의 누적 수입>}`
- `GET /export` → 지금까지의 수락(`accepts`), 정산(`ledger`), 콜(`calls`) 전체. 점검용
- 수락과 완료 요청에는 재시도해도 같은 값인 `idempotency-key` 헤더를 넣는다.
